#  Interactive Birthday Web Experience

An interactive, birthday-themed website built using *HTML5, CSS3, and JavaScript*. This project combines creative UI design, CSS animations, and JavaScript-based interactions to create an engaging, multi-section web experience.

##  Features

- 🎨 **Creative UI Design** 
- 📱 **Responsive Layout** 
- 📅 **Date Validation** 
- 🎂 **Animated Elements** 
- 🎈 **Interactive Balloons**
- 🖼️ **Dynamic Photo Display**
- 💌 **Multi-Section Experience** 
## 🛠️ Technologies Used

- **HTML5** — Page structure and content
- **CSS3** — Styling, layouts, transitions, keyframe animations, and responsive design
- **JavaScript (Vanilla JS)** — Date validation, event handling, DOM manipulation, and dynamic content updates

## What I Learned

Through this project, I practiced:

- Structuring web pages with HTML.
- Creating responsive layouts and animations with CSS.
- Using JavaScript for DOM manipulation and event handling.
- Validating user input and managing interactive page sections.
- Updating images and text dynamically based on user actions.
